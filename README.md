# Radio Classic

Веб-радио с жанрами в интерфейсе iPod Classic. Музыка синтезируется прямо в браузере (Web Audio), работает офлайн как PWA.

## Возможности
- 6 жанров, по 3 станции в каждом, избранное, случайная станция
- Click wheel: мышь, касание, клавиши (↑↓ Enter Esc Space ←→ F R)
- Тёмная и светлая тема, три размера плеера, таймер сна
- Фон реагирует на музыку, управление с экрана блокировки (Media Session)
- Установка на телефон (PWA)

## Запуск
Открыть `index.html` через любой HTTPS-хостинг (например GitHub Pages: Settings → Pages → Deploy from branch → main / root).

## Реальные потоки
В `index.html` в массиве `ST` у станции добавить четвёртое значение: `["Название", сдвиг, темп, "https://.../stream"]`.
